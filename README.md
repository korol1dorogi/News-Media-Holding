# Сигнал

Находит событие в потоке постов, собирает досье с проверкой на фейк и готовит черновик под издание.
Данные синтетические. Запуск: `cp .env.example .env && make setup && make run`, затем http://localhost:5173.
План: [«План победы»](https://docs.google.com/document/d/1UG1O0tvd8P1grRZos_uGmGy4PIYQ2Bhj9QoK_XMZEOQ/edit?tab=t.0).
