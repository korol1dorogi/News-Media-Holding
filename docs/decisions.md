# Решения

Новые решения добавляет лид. Номер не переиспользуется; отменённое решение помечается
«отменено → D-xx».

| ID | Решение | Почему |
|---|---|---|
| D-01 | Python 3.12, FastAPI, SQLite (stdlib sqlite3), pytest, ruff. Фронт: React + Vite + TypeScript strict + Tailwind, одна страница | Сутки на всё; Django и Postgres дают лишнее трение |
| D-02 | Python-пакет называется `radar` | Имя `signal` занято модулем стандартной библиотеки |
| D-03 | Похожесть текстов: TF-IDF по умолчанию. Эмбеддинги (e5-small) — только по флагу и только после согласования зависимости с лидом | Работает офлайн, без скачивания моделей |
| D-04 | LLM: детерминированный MockProvider по умолчанию; OpenAI-совместимый провайдер при `LLM_PROVIDER=openai` | Демо и тесты работают без ключа и без сети |
| D-05 | CI не настраиваем, проверка — `make check` локально перед PR. Демо — на VPS лида за Caddy | Экономим время |
| D-06 | Синтетика: вымышленный город и вымышленные каналы, всё помечено как синтетика | Никаких «фейков» про реальные места и ведомства |
| D-07 | Визуальные признаки медиа (снег, дождь, день, ночь) в MVP берутся из `media/meta.json`, а не из vision-модели | В продакшене их даёт vision-модель; в заявке пишем это честно |
| D-08 | Пока в базе нет событий, API отдаёт фикстуры из `frontend/src/mock` (заголовок `X-Radar-Source: fixtures`) | Фронт и API с первого коммита имеют одну форму; UX1 не ждёт пайплайн |
| D-09 | В `verify.*` и `score.score` передаются все посты replay (посты события — по `event.post_ids`); в `draft.*` — только посты события | Первоисточник и официальное опровержение могут лежать вне кластера; черновик сверяется только со своими источниками |
| D-10 | Node — версия 24 (LTS), в `.nvmrc` | Поддерживается Vite 7 |
