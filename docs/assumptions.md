# Упрощения MVP и путь в продакшен

| Упрощение в MVP | Почему так | Путь в продакшен |
|---|---|---|
| Данные синтетические: вымышленный город, каналы, посты | Нельзя выдумывать события про реальные места и ведомства (D-06) | Сбор из публичных TG-каналов, RSS, сайтов ведомств, бота читателей |
| Поток — replay из `posts.jsonl`, а не живой сбор | Детерминированное демо и тесты | Коллекторы по источникам, очередь, онлайн-обработка |
| Гео и тема — словарь и ключевые слова | Быстро и объяснимо | Классификатор и NER, обученные на архиве холдинга |
| Кластеризация — TF-IDF и косинус в окне времени (D-03) | Офлайн, без моделей | Эмбеддинги (e5 и аналоги), near-duplicate по медиа |
| Веса скоринга заданы руками в `data/profiles` | Нет меток | Метки из архива холдинга: опубликовали событие или нет; дообучение на решениях редактора |
| Признаки фото (снег, дождь, день) — из `media/meta.json` (D-07) | Нет vision-модели в MVP | Vision-модель по кадру |
| Погода — из `weather.json` | Офлайн | API погодного сервиса с историей наблюдений |
| Архив медиа — локальная папка, pHash | Простой и устойчивый к пережатию метод | Индекс по архиву холдинга и открытым архивам, видео по ключевым кадрам |
| Подтверждение официальным каналом — ключевые фразы | Объяснимо и быстро | Классификатор «подтверждает / опровергает» с проверкой человеком |
| LLM — MockProvider (D-04) | Демо без ключа и сети | Открытая модель на своих серверах или API по договору; каскад «дёшево, потом дорого» |
| Черновик генерируется только по кнопке | LLM не вызывается на шуме | То же, плюс бюджет и очередь запросов |
| Сторож опровержений после публикации — только описан | Не успеваем за сутки | Подписка на официальные каналы по опубликованным событиям, алерт редактору |
| SQLite, один процесс, без авторизации | Сутки на всё (D-01) | Postgres, роли редакторов, аудит действий |
| Нет CI (D-05) | Экономим время | CI с `make check` на каждый PR |
| Пока база пуста, API отдаёт фикстуры (D-08) | Фронт работает с первой минуты | Убрать фолбэк, пустая лента — пустой ответ |
