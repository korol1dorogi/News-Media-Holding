# Критерии оценки

Каждый критерий — до 10 баллов. По текстам заявки оценивается 4 критерия из 6, поэтому
заявку не урезаем.

| Критерий | Чем закрыт | Где жюри увидит |
|---|---|---|
| Оригинальность | Первоисточник и граф репостов, pHash по архиву, сверка с погодой, сторож опровержений | Слайд «чего нет у других», демо |
| Реалистичность реализации | Открытые модели, каскад «дёшево, потом дорого», обучение на архиве холдинга, человек в контуре, работающий MVP | Раздел заявки «Как создать», MVP |
| Понятность описания | Одна фраза, одна схема, путь редактора по шагам | Первая страница заявки |
| Представление результата | Видео 2 минуты, живой стенд, скриншоты, замеры из `reports/metrics.json` | Ссылки в начале заявки |
| Степень проработанности идеи | Алгоритмы по этапам, метрики, план оценки, риски и правовые вопросы (`docs/assumptions.md`) | Основной текст заявки |
| Опыт команды | ICPC, ВСОШ по ИБ, Альфа-Будущее (ассистент с guardrails, eval и red team), коммерческий опыт | Раздел заявки «Команда» |
